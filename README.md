# プライバシーポリシー

最終更新日：2026年11月20日

本プライバシーポリシーは、アプリ「あなたはパン屋さんのレジ係です！」（以下「本アプリ」）における利用者の情報の取り扱いについて説明するものです。

## 1. 個人情報の収集について

現在の本アプリは、利用者の氏名、住所、電話番号、メールアドレスなどの個人情報を、アプリを通じて収集することはありません。

また、広告配信サービスやアクセス解析サービスは使用していません。

## 2. ゲームデータの保存について

本アプリでは、ゲームの進行状況、設定、売上履歴などのデータを、利用者の端末内に保存します。

これらのデータは、現在の仕様では開発者のサーバーへ送信されません。

## 3. バックアップについて

本アプリには、ゲームデータをバックアップファイルとして書き出す機能があります。

利用者が自らファイルの保存先や共有先を選択した場合、その保存先のサービスにデータが保存されることがあります。保存先での情報の取り扱いについては、各サービスのプライバシーポリシーをご確認ください。

## 4. アプリ内購入について

本アプリでは、今後、Appleが提供するアプリ内課金機能を利用する予定です。

アプリ内購入を導入した場合、決済はAppleの決済システムを通じて処理されます。決済情報の取り扱いについては、Appleのプライバシーポリシーをご確認ください。

課金機能の導入に伴い、情報の取り扱いが変更される場合は、本ポリシーを更新します。

## 5. 外部サービスについて

本アプリの機能や外部サービスとの連携内容に変更があった場合は、必要に応じて本ポリシーに反映します。

## 6. プライバシーポリシーの変更について

本ポリシーは、法令の改正やアプリの機能変更などに応じて、予告なく変更されることがあります。

変更後のプライバシーポリシーは、本ページに掲載した時点から適用されます。
