# プライバシーポリシー

最終更新日：2026年11月27日

「あなたはパン屋さんのレジ係です！」（以下「本アプリ」）は、パン屋さんゲーム制作室（個人運営。以下「運営者」）が提供するアプリです。

運営者は、本アプリにおける利用者の情報の取り扱いについて、以下のとおり定めます。

## 1. 個人情報の取得について

本アプリでは、利用者の氏名、住所、電話番号などを登録するアカウント機能はありません。

ただし、お客さんの会話やストーリーなどを自由に入力できる機能があります。利用者が入力した文章に個人情報が含まれる場合、その情報はゲームデータとして端末内に保存されることがあります。

## 2. ゲームデータの保存について

本アプリでは、ゲームの進行状況、所持金、売上履歴、設定、解放状況、お客さんの編集内容、会話・ストーリーなどのデータを、端末内に保存します。

これらのゲームデータは、通常のゲーム利用において運営者のサーバーへ自動送信されません。

## 3. バックアップについて

本アプリには、ゲームデータをバックアップファイル（JSON形式）として書き出し、復元する機能があります。

利用者が自ら保存先や共有先を選択した場合、その保存先のサービスにデータが保存されることがあります。保存先サービスの情報の取り扱いについては、各サービスのプライバシーポリシーをご確認ください。

## 4. アプリ内課金について

本アプリでは、Appleのアプリ内課金機能を利用して、有料コンテンツを提供しています。

購入処理、購入情報の確認および購入の復元には、AppleおよびRevenueCatのサービスを利用しています。

これらのサービスでは、購入情報、取引情報、アプリ利用環境に関する技術情報などが処理される場合があります。

運営者は、購入権利の確認および有料コンテンツの提供に必要な範囲で、これらのサービスを利用します。

決済情報の取り扱いについては、AppleおよびRevenueCatそれぞれのプライバシーポリシーをご確認ください。

## 5. 外部サービスについて

本アプリでは、以下の外部サービスを利用しています。

- Apple App Store：アプリの配信およびアプリ内課金
- RevenueCat：アプリ内課金の管理、購入情報の確認および購入復元

また、アプリの購入設定確認などに関連して、アプリの識別情報、OS、アプリバージョン、ビルド番号などの技術情報を運営者のサーバーへ送信する場合があります。

外部サービスにおける情報の取り扱いについては、各サービスのプライバシーポリシーをご確認ください。

## 6. 広告・アクセス解析について

現在、本アプリでは広告配信サービスおよびアクセス解析サービスを利用していません。

## 7. データの保存期間と削除について

ゲームデータは、利用者の端末内に保存されます。

ゲームデータの削除については、端末の設定から本アプリのデータを削除する方法などがあります。ただし、ゲーム内のリセット機能では、一部のデータが削除されない場合があります。

バックアップファイルについては、利用者自身で保存先から削除してください。

## 8. プライバシーポリシーの変更について

本ポリシーは、法令の改正やアプリの機能変更などに応じて、必要に応じて変更することがあります。

変更後のプライバシーポリシーは、本ページに掲載した時点から適用されます。
